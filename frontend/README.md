# ApplicationPipeline — Frontend

React (Vite) single-page app. Talks to the FastAPI backend at `http://localhost:8000`.

## Dev
```bash
npm install
npm run dev     # http://localhost:5173
```

## Tests
```bash
npm test          # Vitest, one run
npm run test:watch
```

See [../docs/architecture.md](../docs/architecture.md) for API contracts,
[../docs/sprints/plan.md](../docs/sprints/plan.md) for what is built and what is planned, and
