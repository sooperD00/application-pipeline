     layer order: the Watches give constraints, not an implementation. Those decisions are
     yours, and the sprint file is where you write down the ones worth keeping.

  5. That the suite is red before you start: 18 known failures in test_tailoring.py, all of them
     [s-41441e]'s. A green suite is not a done-when here, and the frontend suite cannot run at
     all until node_modules exists.

  6. Whether uv pulled its own Python into the image. Only the build log says so, and it says it
     once, in a line that scrolls past.

  7. A rule this leg needs that no file cites. A grep finds citations, never the dependency
     nobody wrote down. This list was assembled by reading, which fails the same way from the

     delete. requirements.txt is the exception: it is generated, and the only fact in it is the
     `uv export` line in its header that records how it was made -- a command that dies with the
